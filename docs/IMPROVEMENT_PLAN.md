# 에디터 현황 진단 및 개선 계획

작성일: 2026-08-19 · 대상 커밋: `c3fcf29` (main)

## 요약

PR #3(`3992b8f`)에서 새 UI 셸(HTML/CSS)과 생성자 초기화 코드만 머지되고 **자바스크립트 구현이 통째로 빠진 상태**입니다. 그 결과 현재 main은:

- 페이지 로드 시마다 `TypeError: this.initTheme is not a function` 발생 (헤드리스 Chromium으로 재현 확인)
- 상단 툴바의 신규 버튼(템플릿·에셋·히스토리·원본편집·테마·명령팔레트 등)과 시작 화면 옵션 3종이 **전부 무반응**
- 기존 기능(업로드, 요소 선택/이동/복제/삭제, 스타일 패널, 실행취소, 다운로드)은 이벤트 바인딩이 예외 발생 이전에 완료되는 덕분에 우연히 동작

즉 "동작하는 구버전 + 죽어있는 신버전 UI"가 겹쳐진 상태이며, 최우선 과제는 앱을 다시 일관된 상태로 복구하는 것입니다.

## 개선 계획

### Phase 1 — 앱 복구 (최우선, 규모: 소~중) ✅ 구현 완료

목표: 콘솔 에러 0, 화면에 보이는 모든 컨트롤이 동작하거나 사라지게.

> 2026-08-19 구현 완료. 헤드리스 Chromium 검증 19항목 전체 통과 (로드 에러 0).
> 추가로 P1 일부를 선반영: 입력창 포커스 시 단축키 가드(#10), Ctrl+D 복제·↑/↓ 요소 이동 단축키.
> Monaco·에셋 팔레트·유사 선택·자동저장·최근 파일은 Phase 2 전까지 UI에서 숨김 처리.

1. `initTheme()` 구현: `localStorage` 테마 저장/복원 + `themeToggleBtn` 토글 + `data-theme` 속성 적용 (CSS는 이미 준비됨).
2. `initGluestackModules()` 구현 — 최소 범위:
   - 시작 옵션: 빈 페이지/샘플 템플릿으로 시작, 로컬 파일 열기(File System Access API, 미지원 브라우저는 버튼 숨김)
   - 패널 open/close 토글: 템플릿·에셋·히스토리 패널, 원본편집 드롭다운
   - 단축키 모달(`?` 버튼·키), 명령 팔레트(Ctrl+K, 기존 동작들 호출)
   - 뷰포트 스위처(iframe 너비 전환)
3. 당장 구현하지 않을 항목(Monaco, 자동저장, 최근 파일, 아이콘 라이브러리 등)은 **UI에서 숨기거나 "준비 중" 표시** — 허위 UI 제거가 원칙.
4. 단축키 가이드 모달을 실제 구현과 일치하도록 수정(구현하거나 표기 삭제).

### Phase 2 — 핵심 버그 수정 (규모: 중) ✅ 구현 완료

> 2026-08-19 구현 완료. 헤드리스 Chromium 검증 16항목 전체 통과, Phase 1 스위트 19항목 회귀 통과.
> 텍스트 편집 스팬에 포커스가 있어도 Ctrl+D / Ctrl+Shift+L/O는 동작하고, Escape가 텍스트 편집을
> 종료하며, 다중 선택 생성 시 텍스트 포커스를 자동 해제해 Delete가 바로 동작하도록 조정.
> Alt+클릭 / Ctrl+Shift+클릭 범위 선택 / Ctrl+A 도 함께 구현되어 단축키 가이드에 복원됨.
>
> 신규 발견(추후 개선): 상단 중앙의 뷰포트 스위처가 부모 문서 오버레이라서 바로 아래 영역의
> iframe 콘텐츠 클릭을 가로챔 — 접기/자동 숨김 등은 Phase 4 UX 개선에서 다룰 것.

5. DOCTYPE 보존: 스냅샷/다운로드 시 `<!DOCTYPE html>` + outerHTML로 직렬화 (#7).
6. `processTextNodes` 제외 목록에 `textarea`, `pre`, `code`, `svg`, `noscript`, `select/option` 추가 (#6).
7. iframe 문서에도 keydown 리스너 등록 + 부모/iframe 공히 입력 요소 포커스 시 단축키 무시 가드 (#5, #10).
8. 드롭 대상이 드래그 요소의 자손이면 무효 처리(`draggedElement.contains(target)`), 드래그 시작을 "이동 거리 5px 초과"로 통일 (#8).
9. `injectEditorStyles`에 `.element-multi-selected` 추가 + 스타일 패널·삭제·복제가 다중 선택 전체에 적용되도록 확장 (#9).
10. 유사 선택 기능 구현(컨텍스트 메뉴 4항목 + 🧲 버튼 + similarDropdown) — 다중 선택 배열에 채워 넣는 방식 (#3).
11. placeholder 이미지를 인라인 SVG data URI로 교체 (#11).
12. `renderHTML`에서 onload를 src 할당 전에 설정하거나 `srcdoc` 방식으로 전환 (#12).

### Phase 3 — 보안·AI 개선 (규모: 소~중) ✅ 구현 완료

> 2026-08-19 구현 완료. 헤드리스 Chromium 검증 16항목 통과, Phase 1·2 스위트(35항목) 회귀 통과.
> iframe은 기본 `sandbox="allow-same-origin"`으로 문서 스크립트를 차단하고(편집 기능은 전부
> 정상 동작 확인), `<script>` 포함 문서 로드 시 사용자 동의로만 `allow-scripts`를 추가함.
> 다운로드 파일에는 원본 스크립트가 그대로 보존됨. AI 기본 모델은 Gemini `gemini-2.5-flash`,
> Claude `claude-opus-5`, GPT `gpt-4o-mini`로 갱신했고, AI 모달의 "모델명" 입력으로 프로바이더별
> 재정의 가능(localStorage). AI에는 편집용 스팬·에디터 클래스·스크립트를 제거한 정리된 HTML을
> 전송하며, HTTP 오류와 Claude `stop_reason: "refusal"`을 명시적으로 처리함.

13. iframe에 `sandbox="allow-same-origin"`(스크립트 차단)을 기본 적용하고, 스크립트 실행이 필요한 경우 사용자 확인 후 허용 (#13).
14. API 키 안내 문구를 "키는 브라우저(localStorage)에 저장되며, 선택한 AI 제공사에만 전송됩니다"로 수정 (#14).
15. AI 모델명을 최신 세대로 갱신하고 설정에서 변경 가능하게 상수 분리. 컨텍스트는 단순 절단 대신 선택 요소 중심 요약 전달 (#15).

### Phase 4 — 아키텍처·품질 (규모: 대) ✅ 구현 완료

> 2026-08-21 구현 완료. 커밋 4개로 나눠 진행: ① 테스트·CI 기반 → ② 히스토리 개편 → ③ 죽은 UI 정리 → ④ 파일 분할.
> 매 단계 Playwright 49케이스 + ESLint 통과, `file://` 직접 실행 콘솔 에러 0건 확인.
>
> **이번에 발견해 함께 고친 버그 2건**
> 1. **되돌리기마다 편집 스팬 중첩** — 복원 경로가 이미 스팬이 있는 스냅샷에 `makeTextEditable()` 을 다시 돌려
>    `.editable-text` 가 한 겹씩 쌓였고, 이 클래스의 `padding` 때문에 되돌릴수록 글자 간격이 벌어졌음.
>    복원 시 리스너만 재바인딩하고 `processTextNodes` 에 재래핑 가드를 추가해 해결.
> 2. **뷰포트 스위처가 아래 콘텐츠 클릭을 가로챔** — 막대에 `pointer-events: none`, 버튼에만 `auto` 를 줘서 해결.
>
> **의도적으로 보류한 것**: #17의 diff 기반 히스토리. 히스토리 패널·복원·셀렉터 복구가 모두 전체 스냅샷을
> 전제로 동작해, 이득(메모리) 대비 회귀 위험이 크다고 판단. 대신 복원 자체를 iframe 재로드에서
> 제자리 교체로 바꿔 체감 속도와 스크롤 보존 문제를 해결했다.
>
> **정정**: #18의 "클릭 핸들러 중복 실행"은 부정확한 진단이었음 — 위임 핸들러가 캡처 단계에서
> `stopPropagation()` 하므로 요소별 리스너는 실행되지 않는 죽은 코드였다(제거는 그대로 진행).

## 추가 작업 — 스타일 인스펙터 확장 & 템플릿 기능 제거 (2026-08-19)

사용자 요청: **"스타일 편집을 편집하기 쉽게끔 극대화"** (폰트·색상 변경, div 안의 요소를 밖으로 빼내기 등 요소 제어), **"템플릿 부분은 사용할 일이 없으니 삭제"**.

### 템플릿 기능 제거

- 상단 `🧩 템플릿` 버튼, 템플릿 패널 마크업, 템플릿 CSS(약 185줄), `bindTemplateLibrary`/`renderTemplateGrid`/`insertTemplate` 및 `GS_TEMPLATES` 데이터, 명령 팔레트 항목까지 전부 삭제
- 히스토리 패널이 템플릿 패널의 헤더 스타일을 빌려 쓰고 있었으므로 `.history-panel-header` 로 분리
- 시작 화면 문구에서 템플릿 언급 제거. 이어서 **"샘플 템플릿으로 시작" 시작 옵션과 `GS_SAMPLE_HTML` 샘플 문서도 제거**(사용자 확인) — 시작 화면은 "빈 페이지에서 시작"·"로컬 파일 열기" 2개 옵션으로 정리되고, 옵션 수에 맞춰 `auto-fit` 그리드로 배치

### 스타일 편집 → 5탭 인스펙터로 확장

기존 패널은 배경/그라데이션/보더/여백/그림자/폰트크기 정도의 9개 컨트롤이었고, 폰트 종류·굵기·정렬·레이아웃·크기 조절이 전혀 없었습니다. 이를 **56개 CSS 컨트롤 + 구조 편집 도구**로 재구성했습니다.

| 탭 | 제공 기능 |
|---|---|
| 🧱 구조 | 선택 이동(부모·자식·형제), **부모 밖으로 빼기 / 앞 요소 안으로 넣기 / div로 감싸기 / 감싸기 해제**, 순서 이동·복제·삭제, 태그 변경(26종), 클래스·ID 편집, 인라인 스타일 복사·붙여넣기·초기화, CSS 직접 입력 |
| 🔠 텍스트 | 글꼴(20종 + 직접 입력), 크기(슬라이더↔숫자 연동), 굵기 100~900, 줄간격, 자간, 글자 색상, 정렬 4종, B/I/U/S 토글, 대소문자 변형, 줄바꿈 |
| 📐 박스 | 너비·높이·최소/최대 너비(자유 단위), margin·padding 4방향 + **4방향 동일 링크**, 테두리(굵기·종류·색) + 한쪽 면만 적용, 둥글기 전체/모서리별, overflow |
| 🎨 배경 | 배경색, 그라데이션(방향 6종), 배경 이미지 URL·크기·반복, 그림자(X·Y·블러·확산·색·투명도·inset), 투명도, **적용 대상 전환형 빠른 색상 팔레트(배경/글자/테두리, 24색)** |
| 🧭 배치 | display, flex(방향·줄바꿈·정렬·gap), 그리드 열, 위치(position + top/right/bottom/left + z-index), 커서, "가로 가운데 정렬"·"블록 가운데" 원클릭 프리셋 |

구현 방식: 컨트롤에 `data-css` / `data-unit` / `data-sync` / `data-group` 속성을 달아 **선언적으로 일괄 바인딩**하고, `loadCurrentStyles()` 가 같은 속성을 읽어 계산된 스타일을 역으로 채웁니다. 값이 없는 자유 입력 칸에는 계산값을 placeholder 힌트로 보여줍니다(`162.172px` → `162px`). 모든 적용은 기존 `applyStyle()` 을 거치므로 **다중 선택 일괄 편집과 undo 가 그대로 동작**합니다.

### 요소 제어 강화 (요청의 핵심)

- **부모 밖으로 빼기**: 껍데기가 비면 자동 정리, body 최상위에서는 안내 메시지
- **앞 요소 안으로 넣기**: 반대 방향 조작 신설 (void 태그 방어)
- **div로 감싸기**: 같은 부모의 다중 선택을 문서 순서대로 하나의 div 로 묶음 (기존엔 단일 요소만, 점선 테두리 강제 삽입)
- **감싸기 해제**: 텍스트 노드까지 모두 보존해 이동 (기존엔 자식 *요소*만 옮겨 글자가 사라짐)
- **태그 변경**: 자식 노드를 그대로 이동시켜 편집 리스너·속성 유지

### 검증

신규 38케이스 스위트 전체 통과, Phase 1~3 회귀(19+16+17) 통과, 콘솔 에러 0건. 검증 중 발견해 함께 고친 실제 버그:

1. **플로팅 툴바가 스타일 패널을 덮어 조작 불가** — 패널 z-index를 툴바 위로 올리고, 툴바가 패널 영역과 겹치면 왼쪽으로 비켜서도록 수정
2. **색상 입력칸이 컬러 피커를 검정으로 되돌림** — 인라인 값이 없을 때 빈 문자열이 피커로 동기화되던 문제. 색상 칸은 계산된 색을 hex 로 표시하고, 유효한 hex 일 때만 피커에 반영

## Phase 5 — A안(정밀) CSS 전면 적용 + 문서 스타일 일괄 적용 ✅

디자인 캔버스에서 세 방향(정밀 / 에디토리얼 / 콘솔)을 비교한 뒤 **A · 정밀**이 선택됐습니다.
기존 토큰을 버리지 않고 끝까지 밀어붙이는 방향이라 교체 범위가 가장 작았습니다.

### 착수 전 실측 — 토큰이 있는데도 지켜지지 않던 상태

| 항목 | 착수 전 | 이후 |
|---|---|---|
| `#007bff` (토큰 밖 파랑) | 25회 | 0 |
| `#e0e0e0` (토큰 밖 테두리) | 17회 | 0 |
| `#6366f1` (다중선택 인디고) | 13회 | 0 (강조색 하나로 통일) |
| 크롬의 보라 그라데이션 | 4곳 | 0 |
| 회색 리터럴(`#666`·`#999`·`#333` 등) | 17회 | 0 |
| `border-radius` 값 종류 | 10종 | 토큰 5종 (+ 원형 `50%`) |
| 중복 선언 규칙 | 3건 | 0 |
| 이모지 아이콘 | 42종 / 100여 개 | 0 (인라인 SVG 55종) |

### ① 크롬 CSS (커밋 `d3caf58`)

무채색 5 + 강조 1로 수렴. 다중 선택은 색을 달리하는 대신 **옅은 채움**으로 구분하고,
AI 프로바이더 배지의 브랜드색 3종도 선택 상태로만 구분하도록 바꿨습니다.
치수는 `--gs-toolbar-h` / `--gs-control-h` 토큰을 새로 두고 툴바 60→52px, 버튼 36→32px.
히스토리 패널·뷰포트 막대·인스펙터의 상단 오프셋을 이 토큰에 묶어 툴바 높이가 바뀌어도 따라옵니다.

`ai.js` 의 프롬프트 예시문과 `index.html` 의 그라데이션 피커 기본값은 **편집 대상 콘텐츠**이므로
그대로 뒀습니다 — 크롬 색과 콘텐츠 색은 다른 문제입니다.

작업 중 발견해 함께 고친 것: 인스펙터 본문이 `max-height: calc(100vh - 250px)` 이라는
magic number 로 높이를 잡고 있어 내용이 잘렸습니다. 세로 플렉스로 바꿔 본문이 남는 높이를
채우고 스스로 스크롤합니다.

### ② 아이콘 (커밋 `94e9d21`)

이모지는 OS·브라우저마다 모양·크기가 달라 정렬이 어긋나고, `color` 를 따라가지 않아
다크 모드와 활성 상태에서 겉돌았습니다. `js/icons.js` 의 `currentColor` 스트로크 SVG 로 교체했습니다.
마크업은 `data-icon` 자리만 두고 부팅 때 `hydrateIcons()` 가 채웁니다.

곁들여 고친 버그: 다운로드 완료 표시가 `textContent` 로 원래 라벨을 복원해 SVG 아이콘이 사라졌습니다.

### ③ 문서 스타일 일괄 적용 — 신규 기능

인스펙터의 다른 탭은 **선택한 요소**에만 인라인 스타일을 넣습니다. 정적 HTML 을 제안서처럼
다듬으려면 문서 단위 수단이 필요해서 여섯 번째 **문서** 탭을 만들었습니다.

- 문서 `<head>` 의 `<style id="doc-theme">` **한 개**를 갱신하는 방식.
  `extractCleanHTML` 은 `#editor-styles` 와 편집용 마크업만 걷어내므로 이 태그는
  **다운로드 결과에 그대로 남습니다** — 정적 산출물이 목적이라 이게 맞습니다
- 적용 범위 토글: `문서 전체`(규칙 주입) / `선택 요소 안`(인라인 + 상속)
- 글꼴 조합 4종 · 색 팔레트 6종(그라데이션 없음) · 그라데이션 평탄화 · 제안서 타이포 정돈(항목별 토글)
- 웹폰트 `@import` 포함 여부를 끌 수 있어 오프라인 배포도 가능

여기서도 실제 버그를 하나 잡았습니다: 문서 테마 저장을 `saveToHistory(label, false)`(200ms 디바운스)로
호출했더니 **연속 클릭이 한 항목으로 합쳐져 되돌리기가 한 단계를 건너뛰었습니다.**
디바운스는 슬라이더·타이핑처럼 연속 입력을 위한 것이고, 버튼 클릭 단위 동작에는 즉시 저장이 맞습니다.
