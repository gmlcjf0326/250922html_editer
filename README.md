# HTML Live Editor

실시간으로 HTML 파일을 편집할 수 있는 웹 기반 편집기입니다. 드래그 앤 드롭으로 HTML 파일을 업로드하고, 브라우저에서 바로 요소를 편집하거나 텍스트를 수정할 수 있습니다.

## 🌐 온라인 테스트

**[250922html-editer.netlify.app](https://250922html-editer.netlify.app)** 에서 바로 테스트해보세요!

## 🚀 주요 기능

### 📁 파일 업로드

- **드래그 앤 드롭**: HTML 파일을 브라우저 창에 끌어다 놓기
- **파일 선택**: 버튼을 통해 HTML 파일 선택
- **지원 형식**: .html, .htm 파일

### ✏️ 실시간 편집

- **요소 편집 모드**: HTML 요소 선택, 이동, 복제, 삭제
- **텍스트 편집**: 페이지 내 텍스트 직접 수정
- **시각적 하이라이트**: 편집 가능한 요소에 마우스 오버 시 시각적 표시

### 🎨 스타일 인스펙터 (5탭)

요소를 선택하고 🎨 버튼(또는 우클릭 → 스타일 편집)을 누르면 열립니다.

- **🧱 구조**: 부모/자식/형제로 선택 이동, **부모 밖으로 빼기**, **앞 요소 안으로 넣기**, div로 감싸기·해제, 순서 이동·복제·삭제, 태그 변경, 클래스/ID 편집, 인라인 스타일 복사·붙여넣기·초기화, CSS 직접 입력
- **🔠 텍스트**: 글꼴 20종 + 직접 입력, 글자 크기, 굵기(100~900), 줄간격, 자간, 글자 색상, 정렬, 굵게/기울임/밑줄/취소선, 대소문자 변형
- **📐 박스**: 너비·높이·최소/최대 너비, margin·padding(4방향 동일 링크 지원), 테두리(면별 적용 가능), 둥글기(모서리별), overflow
- **🎨 배경**: 배경색, 그라데이션, 배경 이미지, 그림자(확산·inset·투명도), 투명도, 빠른 색상 팔레트(배경/글자/테두리 대상 전환)
- **🧭 배치**: display, Flex(방향·정렬·gap), 그리드 열, position·좌표·z-index, 가운데 정렬 프리셋

여러 요소를 선택한 상태에서 값을 바꾸면 **선택한 모든 요소에 한 번에 적용**됩니다.

### 🔧 편집 기능

- **요소 조작**:

  - 요소 위/아래 이동
  - 요소 복제
  - 요소 삭제
  - 새 요소 추가 (버튼, 링크, 이미지, 리스트 아이템)

- **테이블 전용 기능**:
  - 행/열 추가 (위, 아래, 왼쪽, 오른쪽)
  - 행/열 삭제
  - 테이블 셀 편집

### 🔄 되돌리기/다시실행

- **Ctrl+Z**: 되돌리기 (최대 20단계)
- **Ctrl+Y**: 다시실행
- **히스토리 타임라인(🕐)**: 편집 기록을 보고 원하는 시점으로 바로 이동

### ⌨️ 그 밖의 기능

- **명령 팔레트(Ctrl+K)**: 모든 기능을 검색해서 실행
- **다중 선택**: Shift+클릭 / Alt+클릭(같은 태그·클래스) / Ctrl+A(같은 태그 전체)
- **반응형 미리보기**: 전체 · 1440 · 768 · 375
- **다크 모드(Ctrl+Shift+L)**, **단축키 가이드(?)**
- **AI 스타일 변환**: Gemini · Claude · GPT (API 키는 브라우저에만 저장)

### 🔒 보안

- 업로드한 HTML의 스크립트는 기본적으로 **차단**되며, 필요할 때만 사용자 동의로 실행합니다

### 💾 파일 저장

- **다운로드**: 편집된 HTML 파일을 새파일로 로컬에 저장

## 🖥️ 사용법

### 1. 파일 업로드

1. 브라우저에서 `index.html` 파일을 실행
2. HTML 파일을 드래그 앤 드롭하거나 "HTML 파일 선택" 버튼 클릭
3. 파일이 전체화면으로 표시됨

### 2. 요소 편집

1. **요소 선택**: 편집하고 싶은 HTML 요소를 클릭
2. **플로팅 툴바**: 선택된 요소 근처에 편집 툴바가 나타남
   - ↑: 요소를 위로 이동
   - ↓: 요소를 아래로 이동
   - 📄: 요소 복제
   - ✖: 요소 삭제

### 3. 텍스트 편집

1. 편집 가능한 텍스트 위에 마우스를 올리면 연한 배경색이 나타남
2. 텍스트를 클릭하여 직접 편집
3. Enter 키를 누르거나 다른 곳을 클릭하여 편집 완료

### 4. 파일 저장

우상단의 "📥 다운로드" 버튼을 클릭하여 편집된 HTML 파일을 저장합니다.
